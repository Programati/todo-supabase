# todo-supabase

TodoList con React, Supabase, TanStack Query, Zustand and React Router (Data Mode).

## Requirements

- Node.js 20.19+ or 22.12+
- pnpm

## Setup

1. Instala las dependencias:

```bash
   pnpm install
```

2. Copia el archivo `.env.example`, renombralo como `.env.local` y completa las variables con los valores de tu proyecto de Supabase.

3. Levantar el server:

```bash
   pnpm dev
```
